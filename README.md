## See your space in a new light

Turn architectural photographs into lighting concepts in a focused Windows desktop workspace. Explore evening scenes, warmer atmospheres and new lighting directions using presets, custom briefs and your choice of local or cloud AI.

## Download and get started

**LATEST ALPHA RELEASE** - [ALPHA 8](https://github.com/Bloqdigital/DUSK-STUDIO-Releases/releases/tag/v0.1.0-alpha.8)

1. Open this repository's **Releases** section and download the **DUSK Studio Windows Setup installer** (`.exe`).
2. Run the installer and follow the Windows setup wizard.
3. Launch DUSK and follow the Welcome walkthrough to connect a cloud provider, set up optional local rendering, or both.
4. Import a photograph, choose a preset or write your lighting brief, then generate your first study.

### Create your way

- **Cloud:** connect OpenAI, Google Gemini or Krea with your own API key. Usage is billed by the provider. Cloud-only users need no local image model or NVIDIA GPU.
- **Local:** render on compatible NVIDIA hardware. Select **Install local rendering components** during Windows Setup, or add them later through **Connections**. Choose and download your image models in DUSK's Model Library.

The photograph analyser is included with the application. If local rendering is already installed, DUSK takes you straight to choosing a model.

### Explore, compare and develop

Use design-led presets or describe your own atmosphere. Guide fitting placement with Area Inpaint, compare alternatives with the original and build on a generated image to develop the idea further. Keep useful briefs in your Prompt Library, save complete `.dsk` projects and export images to share your lighting direction.

The illustrated user guide is available inside DUSK through **Help → User Documentation**.
